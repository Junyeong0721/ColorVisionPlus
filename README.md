# ColorVision+

ColorVision+는 색각 이상 사용자를 위한 데스크톱 접근성 애플리케이션입니다.

현재 포함된 기능:

- 메인 화면
- 사용자 모드
- 색각 유형 테스트 진입
- 이시하라 색각 테스트
- 테스트 결과 화면

## 사용자 모드 기능명세

사용자 모드는 이미지 파일을 보정하는 기능이 아니라, 사용자의 현재 화면 위에 전체 화면 색상 보정 필터를 적용하는 기능입니다.

- 홈 화면의 `사용자 모드` 카드 또는 내부 화면의 왼쪽 탭에서 진입할 수 있습니다.
- 내부 화면에서는 왼쪽 탭을 통해 홈, 사용자 모드, 색각 유형 테스트, 개발자 모드, 설정 화면으로 이동할 수 있습니다.
- 메인 화면 자체는 기존 카드형 홈 구성을 유지하고, 사용자 모드 진입 후에만 왼쪽 탭을 표시합니다.
- 색각 유형은 `적색약`, `녹색약`, `청색약`, `일반 보기` 중 선택할 수 있습니다.
- 색각 유형 선택 시 현재 보정 유형 카드의 원형 색상 표시가 유형에 맞게 변경됩니다.
  - 적색약: 빨간색
  - 녹색약: 초록색
  - 청색약: 파란색
  - 일반 보기: 연한 회색
- `전체 화면 보정` 영역에서 화면 보정을 켜거나 끌 수 있습니다.
- 화면 보정은 Windows 전체 화면 색상 필터 API를 우선 사용합니다.
- Windows 전체 화면 색상 필터 API를 사용할 수 없는 환경에서는 투명 오버레이 방식으로 대체 실행합니다.
- 보정이 켜진 상태에서 색각 유형이나 조절값을 변경하면 현재 화면에 즉시 다시 반영됩니다.
- 단축키 `Ctrl+Alt+C`로 왼쪽 오버레이 메뉴를 열고 닫을 수 있습니다.
- 왼쪽 오버레이 메뉴에서는 화면 보정 켜기/끄기, 색각 유형 선택, 보정 강도 조절, 사용자 모드 열기, 앱 종료를 수행할 수 있습니다.
- 오른쪽 아래 Windows 트레이 아이콘 우클릭 메뉴에서 `열기`, `화면 보정 켜기/끄기`, `오버레이 메뉴`, `오버레이 위치 초기화`, `설정 초기화`, `앱 종료`를 실행할 수 있습니다.
- 앱 창을 닫으면 프로그램은 종료되지 않고 오른쪽 아래 트레이 아이콘으로 백그라운드에 남습니다.
- 백그라운드 상태에서는 `Ctrl+Alt+C` 또는 트레이 메뉴로 다시 열고, 실제 종료는 트레이 메뉴의 `앱 종료`를 사용합니다.
- 보정 강도 기본값은 색각 유형별 프리셋을 사용합니다.
  - 일반 보기: 0
  - 적색약: 60
  - 녹색약: 60
  - 청색약: 60
- 색각 유형별 추천 보정 방향은 다음과 같습니다.
  - 적색약: 빨강을 주황/황색 계열로 이동시키고, 초록은 유지하면서 명도 차이를 확대합니다.
  - 녹색약: 초록을 청록 계열로 이동시키고, 적색은 유지하면서 명도/채도 차이를 확대합니다.
  - 청색약: 파랑은 보라/청록 계열로 이동시키고, 황색은 주황 계열로 이동시킵니다.
- 세부 조절 기본값은 모든 유형에서 동일하게 시작합니다.
  - 대비 강화: 20
  - 채도 조절: 0
  - 밝기 조절: 0
- 세부 조절값은 기본값으로 시작하지만 사용자가 직접 변경할 수 있습니다.
- `세부 조절 및 추천 필터` 영역에서는 추천 필터 설명, 선택 유형 색상 스와치, 보정 전/후 색상 미리보기를 표시합니다.
- `프로필 저장` 버튼으로 현재 사용자 모드 설정을 저장할 수 있습니다.
- 색각 유형 테스트 결과 화면의 `화면 보정 적용하기` 버튼을 누르면 테스트 결과에 맞는 사용자 모드 추천 프리셋으로 이동합니다.

## 실행 방법

```powershell
cd desktop_app
python -m pip install -r requirements.txt
python main.py
```

Windows에서는 `desktop_app/run_colorvision.bat` 파일을 실행해도 됩니다.

## 프로젝트 구조

```text
desktop_app/
  main.py

  run_colorvision.bat
  assets/
  views/
```
