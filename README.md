# ColorVision+

ColorVision+는 색각 이상 사용자를 위한 데스크톱 접근성 애플리케이션입니다.

현재 포함된 기능:

- 메인 화면
- 색각 유형 테스트 진입
- 이시하라 색각 테스트
- 테스트 결과 화면

## 실행 방법

```powershell
cd desktop_app
python -m pip install -r requirements.txt
python main.py
```

Windows에서는 `desktop_app/run_colorvision.bat` 파일을 실행해도 됩니다.

## 프로젝트 구조

```text
desktop_app/
  main.py
  requirements.txt
  run_colorvision.bat
  assets/
  views/
```
